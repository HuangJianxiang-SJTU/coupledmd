# CoupledMD

GPCR–G-protein MD web resource — 222 active-state ternary complex simulations with precomputed pocket, gateway, and reorganization analysis.

## Quick Start

```bash
# 1. Set up environment
cp .env.example .env
# Edit .env to set DATA_ROOT and ANALYSIS_SRC for your host

# 2. Run the data pipeline (first time only)
python scripts/p0_freeze_cohort.py
python scripts/p1_ingest.py
python scripts/p2_serialize.py
python scripts/p5_build_viz_tier.py   # optional: --n 20 for testing

# 3. Build the frontend
cd frontend && npm install && npm run build && cd ..

# 4. Start the server
# Development (API only):
uvicorn api.main:app --port 8000 --reload

# Production (API + nginx):
docker compose up -d
```

## Data Pipeline

| Step | Script | Description |
|------|--------|-------------|
| P0 | `p0_freeze_cohort.py` | Read inventory CSV, apply corrections, validate files, write `systems_master.csv` |
| P1 | `p1_ingest.py` | Upsert 222 systems into SQLite (`systems`, `system_pocket_files`, `system_gateway_files` tables) |
| P2 | `p2_serialize.py` | Read precomputed analysis from `ANALYSIS_SRC`, write API-ready JSON under `data/api/v1/` |
| P5 | `p5_build_viz_tier.py` | Strip membrane/water/ions, write decimated XTC (~200 frames) + reference PDB under `data/viz/` |

All scripts read `ANALYSIS_SRC` and `DATA_ROOT` from environment variables. P5 accepts `--n N` to process only the first N systems.

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/health` | Health check with system count |
| GET | `/api/v1/families` | G-protein family summary with counts |
| GET | `/api/v1/systems` | List systems with filters (`family`, `uniprot`, `gene`, `trajectory_type`, `provenance`) |
| GET | `/api/v1/systems/{sid}` | Full system metadata |
| GET | `/api/v1/systems/{sid}/pockets` | Pocket data (GPCRdb-mapped or raw) |
| GET | `/api/v1/systems/{sid}/gateways` | Gateway metrics |
| GET | `/api/v1/systems/{sid}/pocketgrid` | Pocket occupancy grid (NPZ download) |
| GET | `/api/v1/systems/{sid}/viz/structure` | Reference PDB for NGL |
| GET | `/api/v1/systems/{sid}/viz/trajectory` | Decimated XTC for NGL |
| GET | `/api/v1/systems/{sid}/viz/meta` | Viz file metadata (frames, atoms, sizes) |
| GET | `/api/v1/consensus/pockets/druggable` | Consensus druggable pocket clusters |
| GET | `/api/v1/consensus/pockets/orthosteric` | Consensus orthosteric pockets |

| GET | `/api/v1/consensus/nominations` | Druggable pocket nominations |
| GET | `/api/v1/consensus/reorg` | Partner-switching reorganization |

Interactive docs: `/api/docs` (Swagger) and `/api/redoc` (ReDoc).

## Deployment

### Docker Compose (recommended)

```bash
# Generate self-signed certs for development
mkdir -p certs
openssl req -x509 -newkey rsa:2048 -keyout certs/privkey.pem \
  -out certs/fullchain.pem -days 365 -nodes -subj "/CN=localhost"

# Build and start
docker compose up -d

# Check health
curl http://localhost/api/v1/health
```

### Production with Let's Encrypt

1. Point your domain's DNS to the server
2. Install certbot and obtain certificates:
   ```bash
   certbot certonly --standalone -d yourdomain.org
   ```
3. Set `SSL_CERT_DIR` in `.env` to the certbot live directory
4. `docker compose up -d`

### Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `DATA_ROOT` | `.` | Project root (data/, db/, api/) |
| `ANALYSIS_SRC` | — | Read-only analysis source directory |
| `DATABASE_URL` | `sqlite:///db/coupledmd.sqlite` | Database connection string |
| `API_PORT` | `8000` | API server port (container-internal) |
| `HTTP_PORT` | `80` | Nginx public HTTP port |
| `HTTPS_PORT` | `443` | Nginx public HTTPS port |
| `SSL_CERT_DIR` | `./certs` | Directory with fullchain.pem + privkey.pem |
| `CORS_ORIGINS` | (empty) | Comma-separated CORS origins (usually not needed) |
